# ETIC Focus

ETIC Focus is a responsive Pomodoro timer for focus sessions, breaks, and rest periods.

## Features

- Pomodoro timer with focus, break, and rest modes
- Responsive timer card and controls
- ETIC branding, logo, and favicon
- Doodle-style side artwork

## Tech Stack

- React 19
- Vite
- Tailwind CSS v4

## Development

```bash
cd pomodoro-app
npm install
npm run dev
```

## Build

```bash
cd pomodoro-app
npm run build
```
